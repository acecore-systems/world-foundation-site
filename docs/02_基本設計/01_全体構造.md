# 全体構造

## 構成

| 区分 | 役割 |
| --- | --- |
| `world-foundation` | 公開するMarkdownの正本を保持する |
| `scripts/sync-content.mjs` | 正本をStarlight用の生成コンテンツへ同期する |
| Astro / Starlight | 設計文書をWeb表示へ変換する |
| Cloudflare Pages | GitHub連携でビルドと公開を行う |
| Vectorize / D1 | Productionの意味検索とレート制限を担う |
| Pagefind | Vectorize障害時のブラウザ内検索を提供する |

## ビルド経路

1. `world-foundation`の正本を同期スクリプトが読み込む。
2. 生成コンテンツ、検索corpus、公開マーカーを作成する。
3. Cloudflare PagesがGitHub連携でStarlightサイトを公開する。
4. 保護されたProduction同期経路だけが検索indexを書き込む。
