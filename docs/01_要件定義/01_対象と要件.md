# 対象と要件

## 目的

`world-foundation`にある正本Markdownを、Webで閲覧・検索できる形に変換して公開する。

## 要件

- 設計本文の正本は`world-foundation`に残し、このリポジトリでは表示、同期、ビルド、公開を扱う。
- `src/content/docs/`の生成物は手編集しない。
- Cloudflare PagesはGitHub連携で`main`を公開する。
- Vectorizeが利用できない場合でも、ブラウザ内Pagefindによる検索へフォールバックできる。

## 境界

- 公開文書の構造変更は、正本リポジトリと同期設定への影響を確認してから行う。
- PreviewはProductionのVectorize bindingを持たない。
